这里是 Syerain 的博客。写古诗文，也折腾设备和内核；偶尔记一点没想清楚的事。

## 这个站怎么搭的

主题是 WordPress 官方的 [Twenty Twenty-Three](https://wordpress.org/themes/twentytwentythree/)，但这里没有服务器：内容以 Markdown 存在仓库里，构建时用 WordPress Playground 渲染成纯静态 HTML，托管在 GitHub Pages 上。所以你看到的排版与主题演示站一致，而背后没有 PHP、没有数据库。

构建脚本和迁移记录都在[仓库](https://github.com/Syerain/Syerain.github.io)的 `source` 分支里，欢迎参考。
